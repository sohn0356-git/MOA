# 묵상 말씀 가독성

- 새로 선택하는 두 언어 말씀에 `[한국어]`, `[English]` 등의 안내문을 붙이지 않는다. 각 언어의 본문과 절 번호·줄바꿈은 유지한다.
- 기존 글·임시저장·편집 화면의 오래된 언어 꼬리표는 표시할 때만 제거한다. 기존 비공개 원문을 일괄 수정하지 않으며, 본문을 수정하지 않은 저장은 기존 인용을 보존한다.
- 공유 묵상 캡션에서는 말씀 구간의 안내만 정리하고 사용자가 직접 쓴 묵상·적용·기도에 들어 있는 대괄호 문구는 보존한다.
- 읽기 본문·선택 말씀·묵상 상세·작성 입력란은 시스템 본문 글꼴, 17px 크기, 1.9 줄 높이, 0.01em 자간을 적용한다. 한글 단어 단위 줄바꿈과 긴 단어의 화면 내 줄바꿈을 함께 지원한다. 번역 본문의 명암을 높이고 외부 글꼴 요청은 추가하지 않는다.
- 검증: 191 단위/컴포넌트 테스트와 360/768/1440px Chromium 검증. 두 언어 본문 유지, 언어 안내 부재, 글자 크기·줄 높이·본문 폭, 새로고침 뒤 임시저장 복원 및 기존 인용의 원문 보존을 확인했다.
