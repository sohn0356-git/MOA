# 말씀 선택과 친구 기능

말씀 본문은 높이 제한이나 내부 스크롤 없이 페이지 전체에서 자연스럽게 읽는다. 말씀을 선택했을 때만 우측 아래에 46px 원형 묵상 버튼과 선택 절 수를 표시한다. 플로팅 버튼은 본문 위에 겹쳐 표시하고 본문 우측 여백을 추가하지 않아 말씀 너비를 유지한다. 본문 끝의 기존 큰 묵상하기 버튼은 항상 유지하고, 해당 버튼이 내비게이션 위의 화면에 보이기 시작하면 원형 버튼을 200ms 동안 투명해지며 아래로 살짝 이동하도록 숨긴다. 하단 버튼이 화면 밖으로 나가면 다시 나타난다. 숨길 때는 DOM을 유지해 전환 효과를 보존하고 포인터 입력·키보드 포커스·접근성 트리에서 제외한다. 동작 줄이기 설정에서는 전환 효과를 생략한다. 예전의 전체 너비 고정 도크와 뷰포트 높이 계산은 제거했다. 다시 선택 창은 본문과 완료 버튼이 별도 공간을 사용한다. 사진 안내는 묵상하며 마음에 남은 장면을 담는 표현으로 변경했다. 임시저장 복원 카드와 자동 저장 표시도 기존 디자인에 맞추되 저장 방식은 유지했다. 사진 업로드의 기존 AI 계정 제한은 유지한다.

작성자 프로필에서 로그인한 사용자는 친구 요청, 취소, 수락을 할 수 있다. 내 기록의 친구 관리에서 수락·거절, 친구 삭제, 그룹 생성·이름 변경·삭제와 멤버 관리를 제공한다. 요청과 수락 소식은 앱 내 알림이며 앱을 닫아도 요청이 서버에 남는다. 운영체제 푸시 알림은 아니다. 상단 알림 버튼은 홈 아이콘의 피드 탭에서만 표시한다. 설정의 친구 알림과 예배당 알림은 계정에 저장되며 각각 친구 배지와 새 중보기도 미확인 표시를 제어한다. 알림을 꺼도 요청·기도제목은 삭제되지 않는다.

## 데이터 및 권한

- friendRequests/{from}__{to}: 요청자와 수신자만 조회. 각 참여자는 자신의 from/to 인덱스로만 목록 조회 가능. 요청 생성은 본인 from의 pending만 허용하며 pending 수락·거절은 수신자만 가능하다. 거절한 요청의 재전송은 요청자만 가능하다. 참여자는 관계를 삭제할 수 있다. 취소는 트랜잭션으로 아직 pending인 요청만 제거한다.
- users/{uid}/friendGroups: 소유자만 조회·수정. 신규 멤버는 수락된 친구만 허용한다. 친구 삭제 시 본인의 그룹에서도 제거한다.
- users/{uid}/friendNotificationReads 및 notificationPreferences: 소유자만 조회·수정. 읽음 시각 및 두 알림 bool을 검증한다.
- 기존 묵상·공개 피드·사진 업로드 권한은 유지한다.

친구 그룹은 현재 정리용이다. 선택 그룹으로 묵상을 공유하는 기능은 후속 계획이며 아직 공개 범위를 제한하지 않는다. 후속 구현은 그룹 멤버 정보만 신뢰하지 말고 현재 수락된 관계까지 확인하는 서버 읽기 권한과 수신자 조회 인덱스를 함께 구현해야 한다. 상대방 소유 그룹에 남을 수 있는 오래된 멤버 참조가 접근 권한을 부여해서는 안 된다.

## 검증

전체 단위 테스트, production build, 기존 DB/Storage 규칙과 추가 친구 규칙 에뮬레이터 검증을 수행한다. 실제 Auth/DB 에뮬레이터 브라우저 두 계정으로 오프라인 수신자, 취소/재요청/수락, 알림 읽기, 그룹 변경·재접속 보존, 예배당 배지 토글, 친구 삭제를 확인한다. 360/768/1440px 말씀 화면은 자연스러운 전체 본문 높이, 선택 전후 원형 버튼 표시, 선택 전후 동일한 본문 너비, 아래 버튼의 가시성에 따른 사라짐·재표시와 포커스 제외, 두 묵상 버튼의 동작을 확인한다. 다시 선택 창은 본문과 완료 버튼 경계도 비교한다. 기존 피드, AI 사진 업로드, 시작 화면 테스트도 재검증한다.


## 내 기록 탭 구성

내 기록의 필터는 묵상·기도·질문·친구다. 묵상은 선택 날짜의 글 및 첨부 사진과 과거에 별도로 올린 사진을 함께 표시한다. sourceEntryId로 묵상과 연결된 사진은 중복 목록에서 제외한다. 친구 탭은 기존 친구 요청·친구 삭제·그룹 관리를 모달 대신 본문에 바로 표시하고 날짜 달력은 숨긴다. 로그인 전에는 로그인 안내를 표시한다. 상단의 별도 친구 관리 카드는 제거하며 홈의 알림 창은 유지한다.
