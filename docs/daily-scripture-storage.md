# 오늘 말씀 저장과 갱신

GitHub Actions의 Update Daily Meditation Verse가 날짜별 원본을 검증하고 두 곳을 갱신한다.

- Firebase RTDB `verse/{year}/{MMDD}`: 날짜, 장절 범위, 한국어 본문, 번역명과 출처.
- Git `public/scripture/{ko,en,ja}/{book}.json`: 언어·책·장·절별 본문 캐시. 워크플로가 변경분을 커밋하고 GitHub Pages에 배포한다.

앱의 `fetchFirebasePlan`은 먼저 Firebase에서 날짜별 정보를 읽는다. 한국어는 DB 본문을 우선 사용하고 Git 캐시도 조회한다. 영어·일본어는 같은 장절 범위의 Pages JSON을 읽는다. Firebase에 해당 날짜가 없으면 Git 본문이 있어도 날짜별 본문을 구성하지 않는다. 따라서 현재 구조는 Git 전용 저장이 아니다. 이번 수정은 저장소 이전을 포함하지 않는다.

예약은 한국 시간 23:45, 23:50, 23:55, 00:00, 00:05, 00:10, 00:15이다. UTC 표현은 각각 `45,50,55 14 * * *`와 `0,5,10,15 15 * * *`다. GitHub Actions가 허용하는 최소 간격인 5분을 사용한다. 매시간 17분 복구 작업도 유지한다. 작업이 겹치면 기존 concurrency 설정으로 직렬 처리하며, 같은 본문은 DB 재기록과 Git 커밋을 생략한다.

각 실행은 한국 날짜 기준 오늘을 먼저 갱신하고, 내일·모레는 원본이 공개된 경우에만 선저장한다. 원본의 날짜가 다르거나 본문이 불완전하면 저장하지 않는다. 미래 본문 조회 실패로 오늘 본문 저장을 취소하지 않는다. GitHub 예약 작업의 실행 지연·누락 가능성 때문에 정각 표시를 보장하지는 않는다.
