# 예배당 입장 화면과 기도 완료

예배당 입장 상태를 sanctuary의 data-entered 속성으로 표시한다. 예배당 탭에서 실제로 입장한 동안에만 공통 상단 제목·계정/로그아웃 헤더를 숨기고 본문 위 여백을 제거한다. 로비로 돌아가면 헤더가 복원되며 다른 탭의 헤더에는 영향을 주지 않는다. 입장 전 로그인 및 캐릭터 편집 흐름은 유지한다.

기도 타이머의 기존 단일 완료 처리에서 navigator.vibrate([180,100,180])를 호출한다. 이미 완료된 세션의 중복 호출은 기존 finished 가드로 방지한다. 일시정지나 초기화에는 진동하지 않는다. API 미지원·기기 차단 등은 완료 기록과 화면 안내에 영향을 주지 않도록 처리한다. 웹 진동 API 지원 기기에서 사용하는 기능이며 별도의 운영체제 백그라운드 알람은 아니다.

말씀 본문 맨 아래 묵상하기 버튼 뒤에는 28px 여백을 추가한다. 플로팅 버튼의 기존 나타남·사라짐 동작은 유지한다.

검증: 타이머 일시정지/재개 후 완료 진동 1회 및 미지원·예외 처리를 컴포넌트 테스트로 확인한다. 360/768/1440px Chromium에서 입장 후 헤더 숨김·예배당 상단 배치·로비 복귀 시 헤더 복원, 가상 시계로 실제 기도 완료 진동을 검사한다. 말씀 브라우저 테스트는 하단 버튼 아래 28px 공간도 실측한다.
