# 예배당과 묵상·기도 통합
하단 다섯 탭: 피드 / 묵상·기도 / 예배당 / 질문 / 내 기록. 기존 기도 기능과 묵상 데이터 경로·공개 범위·수정 권한은 유지하고 두 번째 탭 안에서 전환한다.

예배당은 AppShell의 실제 로그인 계정만 입장한다. 별도 AI 활동 아이디 세션은 로그인 게이트를 해제하지 않는다. 로그인 전에는 개인 메모·좌석·촛불 기록 컴포넌트를 마운트하거나 저장소를 읽지 않는다. 로그아웃 또는 계정 전환 시 해당 컴포넌트를 즉시 교체한다.

새벽/낮/저녁 빛, 네 자리 선택, 직접 누르는 종소리, 촛불, 5/10/20분 기도 타이머, 개인 기도 메모를 제공한다. 기록은 로그인 UID로 분리하여 이 브라우저에 저장하며 다른 기기와 동기화하지 않는다. 실제 방문 인원이나 예배 일정을 꾸며 표시하지 않는다. 개인 메모의 자동 공개나 자동 기도 게시도 하지 않는다.
