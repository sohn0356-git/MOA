# 새로고침과 3D 프로필 아바타

- 시작 로딩 화면은 같은 탭의 첫 진입에만 표시한다. `sessionStorage`에 이미 진입했다는 표시가 있거나 브라우저 탐색 유형이 새로고침/뒤로가기이면 시작 화면을 건너뛴다. 첫 렌더 전에 정적 HTML 로딩 그림도 같은 조건으로 숨겨 깜빡임을 막는다.
- 새로고침 중 계정/글 복원은 배경에서 진행한다. 프로필과 예배당의 로그인 제한은 기존 인증 상태를 따르며 준비되지 않은 계정에 권한을 주지 않는다. 사용자가 직접 Google 로그인을 누른 경우의 진행 화면은 유지한다.
- 프로필·예배당·피드 원형 아바타·작성자 상세·댓글은 `sanctuary/avatars/{uid}`의 현재 외형을 사용한다. 과거 Google 프로필 사진은 아바타 표시로 사용하지 않는다.
- 비로그인 독자는 작성자 한 명의 공개 외형만 실시간 조회할 수 있다. 전체 아바타 목록, 접속 기록, 공동 기도제목은 공개하지 않으며 수정 권한도 기존 소유자에게만 있다.
- 검증: 재마운트/새로고침 시작 화면 생략 테스트, 정적 HTML 재진입 테스트, 실제 모바일/태블릿/데스크톱 새로고침 테스트, 프로필을 두 번 편집했을 때 비로그인 독자의 3D 외형이 새로고침 없이 동기화되는 Auth+Database 브라우저 테스트, 공개 범위와 소유자 권한 테스트.
