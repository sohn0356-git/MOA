# 이메일 계정 로그인

- 비로그인 헤더에서 구글 로그인 옆의 이메일 버튼으로 이메일/비밀번호 창을 연다. 예배당, 프로필, 작성자 창의 로그인 안내에서도 이 창을 열어 이메일 또는 구글 계정을 선택할 수 있다.
- 기존 이메일 계정 로그인과 새 이메일 계정 회원가입을 Firebase Authentication에 연결했다. 가입 시 비밀번호 확인과 6자 이상 조건을 적용한다. 비밀번호 보기/숨기기를 지원하고 실패 시 입력은 유지한다.
- 이메일/비밀번호는 인증 요청에만 전달하며 앱 저장소에 기록하지 않는다. 이메일만 앞뒤 공백을 정리하고 비밀번호의 공백은 보존한다.
- 기존 지속 로그인 설정을 동일하게 사용한다. 성공한 이메일 인증 이후에만 이전 AI 활동 세션을 지우고 본인 계정 권한으로 전환한다. 로그인 오류나 회원가입 오류를 한국어로 안내한다.
- 이메일 인증은 입력창 안에서 진행 상황을 표시하며 전체 시작 로딩 화면을 다시 띄우지 않는다. 사용자 정보가 복원되기 전에는 예배당 권한을 주지 않는다.
- 검증: 계정 생성/오류/비밀번호 보존 hook 테스트, 가입 확인/실패 후 재시도/중복 제출 방지 UI 테스트, AppShell 버튼 연결 테스트, 실제 Auth 에뮬레이터로 회원가입·로그인·브라우저 재시작 유지·잘못된 계정의 예배당 접근 차단·로그아웃 검증.
