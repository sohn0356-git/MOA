# Compact chapel and intercession board
The chapel now concentrates on its room. Large welcome, visitor, character and prayer cards have been replaced by a small header and presence strip. The timer is a compact control row, the candle is a room action, and private notes are a collapsed disclosure with the existing account-local storage and failure guards.

A custom SVG wooden prayer box in the chapel opens a native modal noticeboard with pinned paper notes. The list supports active/answered/mine filters, live prayer details, author editing/deletion/answer status, and unique intercession acknowledgments. The existing database paths, authorship, acknowledgments and draft storage key are preserved. Draft state stays mounted while the modal is closed and can be resumed after reopening/reload. Storage failures guard navigation/update. Native dialogs trap focus and Escape closes them, then returns focus to the opener. The room stops walking before opening the box.

The avatar supports standing, sitting and kneeling; walking returns it to standing. CSS cuboid articulation bows the head and bends the arms/legs without additional 3D packages or image downloads. Posture is shared as an optional validated presence field, with old records defaulting to standing. Existing clients without the field remain valid.

Reference: https://0won.co.kr/church/ (indexed content: quiet shared space and object/seat actions). Direct loading of the former Claude artifact is blocked; no claim is made to have viewed that artifact. The mailbox, paper board and poses are original SVG/CSS.

Verification covers posture transitions, permission validation, native-modal focus/close and draft restoration, responsive room/board screenshots, and two real emulator-authenticated accounts sharing poses and intercession interactions. The Faith-only entry and bundle guards remain enabled.
