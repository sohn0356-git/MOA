# MOA Faith — social reading design
Scope: MOA Faith only. AI City retains its root design direction.

Reference method: VoltAgent/awesome-design-md README and its Pinterest analysis at https://getdesign.md/pinterest/design-md (reviewed 2026-10-31). This is an original implementation, not a claim of Instagram affiliation or a copied brand system. Pinterest's image-first principle informs the art presentation; familiar SNS author → image → caption → reactions order informs the feed.

- White reading canvas, charcoal text, purple #7353a6 actions, coral #df766c accents. No fake activity counters or story rings.
- One centered 680px reading column on desktop, full available mobile width. Sticky compact header, safe-area-aware five destination bottom navigation.
- Feed: a real write action, a compact praise section, author/avatar/time, uncropped artwork, collapsible long caption, prayer and comments. Keep full text keyboard accessible through native details.
- Composition: author selection and scripture context before memo, optional image with preview, audience choice, one save action. Permission-switch and image-preparation states disable posting.
- Existing owner checks, record identity, timestamps, reactions and comments must survive edits. No data migrations for a visual redesign.
- 44px touch targets where practical; visible focus; real labels; 14–15px body at 1.7–1.85 line-height; reduced motion support. Check mobile and desktop, feed, writing and existing tests before shipping.
