# Our beginning — wedding planner

Scope: this directory only. Reference: [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md), especially its [Oura analysis](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/oura/DESIGN.md), MIT. Reviewed the source design document: adapt its warm-paper editorial hierarchy, earthy surfaces, hairline dividers, pill actions and generous spacing. This is an original wedding adaptation, not a brand replica.

- Paper #f7f1e8, ink #392f2c, clay #9b5d52, sage #dce1d2, hairline #e1dcd3. Warm stone primary actions; blue reserved for keyboard focus.
- Large serif headings, existing local Korean/system sans for reading. No proprietary or remotely loaded fonts.
- A quiet arch and interlocking rings illustrate the beginning; no fabricated photos, venues or saved records.
- Five persistent bottom destinations: home, Korea map, checklist, budget, notes. Keep 44px touch targets and safe-area spacing.
- Map uses actual OpenStreetMap tiles, geographic Web Mercator coordinates, visible attribution, pan and zoom, plus an equivalent saved-place list. No API key required. Network is required for tiles.
- Editable pins: any six-digit color, emoji/text icon, title, body, coordinates. Native modal focus management, Escape, explicit delete confirmation and save failure feedback.
- Account-scoped local browser persistence; state the lack of device sync. Never reuse the shared suggestions database for private wedding records.
- At narrow widths, stack map and list; retain readable forms and all five bottom buttons. Respect reduced motion.
